# CONTRATO DE PROGRAMACIÓN

## SOFTWARE DE CÁLCULO, DISEÑO Y CUANTIFICACIÓN DE CUBIERTAS LIGERAS Y CERCHAS

### 1. IDENTIFICACIÓN DEL PROYECTO

**Nombre provisional:** CUBIERTA PRO

**Tipo de aplicación:** Software profesional de escritorio para cálculo, predimensionamiento, diseño geométrico, análisis, cuantificación y documentación técnica de cubiertas ligeras y sus estructuras portantes.

**Proyecto:** Independiente de ARQ GEN.

**Tecnología principal:**

* Rust.
* Tauri.
* HTML5.
* CSS3.
* JavaScript/TypeScript.
* Base de datos local.
* Motor matemático y estructural desarrollado principalmente en Rust.

**Plataforma principal:**

* Windows 10/11 de 64 bits.

**Plataformas secundarias previstas:**

* Linux.
* Posible macOS en una fase posterior.

**Funcionamiento:** 100 % local y offline.

**Dependencia de Internet:** Ninguna durante la ejecución del programa.

**IA:** No necesaria para el funcionamiento del programa.

---

# 2. OBJETIVO GENERAL

Desarrollar un software profesional capaz de calcular, predimensionar, diseñar y cuantificar cubiertas ligeras de diferentes configuraciones geométricas y estructurales, permitiendo al usuario definir una cubierta desde sus dimensiones, cargas, materiales, perfiles y condiciones de apoyo, obteniendo como resultado:

* Geometría completa.
* Tipo de cubierta.
* Tipo de cercha.
* Dimensiones de la cercha.
* Pendientes.
* Separación entre cerchas.
* Correas.
* Arriostramientos.
* Perfiles estructurales.
* Longitudes de elementos.
* Cantidades de materiales.
* Tornillería.
* Soldadura.
* Placas y accesorios.
* Cubierta.
* Impermeabilización cuando corresponda.
* Canalones.
* Bajantes.
* Elementos auxiliares.
* Peso estimado.
* Cargas.
* Reacciones.
* Esfuerzos.
* Comprobaciones estructurales.
* Presupuesto cuantitativo.
* Planos y esquemas.
* Memoria técnica.

El programa deberá permitir pasar de:

**DATOS DEL PROYECTO → GEOMETRÍA → CÁLCULO → ESTRUCTURA → MATERIALES → CANTIDADES → DOCUMENTACIÓN**

---

# 3. FILOSOFÍA DEL SOFTWARE

El sistema deberá construirse con una arquitectura modular.

El motor de cálculo deberá estar completamente separado de:

* Interfaz gráfica.
* Base de datos.
* Sistema de dibujo.
* Sistema de reportes.
* Sistema de presupuesto.
* Importación/exportación.
* Configuración.

Esto permitirá modificar posteriormente la interfaz sin alterar el núcleo matemático.

El cálculo crítico deberá ejecutarse en Rust.

Tauri será utilizado principalmente como capa de escritorio y comunicación entre la interfaz y el motor Rust.
